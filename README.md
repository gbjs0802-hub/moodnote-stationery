# 무드노트 Moodnote

취향을 기록하고 만드는 시간을 위한 반응형 문구·취미 편집숍 웹사이트입니다.

**Live:** https://moodnote-stationery.web.app

## 주요 기능

- 다이어리, 낱개 필기류, 다꾸 도구, 나만의 사진 스티커와 시판 스테디셀러를 포함한 32개 상품
- 말랑이, 슬라임, 레진 DIY 및 가을 시즌 컬렉션
- 반려동물 사진과 이름을 받는 커스텀 스티커 주문 화면
- 검색, 카테고리·가격·분위기 필터, 정렬, 찜과 장바구니
- 배송지와 결제수단을 선택하는 데모 주문·결제 및 완료 화면
- Firebase Authentication 기반 Google 로그인과 프로필·로그아웃 메뉴
- 28개 전 상품의 핵심 특징, 사용법, 옵션, 사양, 배송·교환 정보를 담은 상세페이지
- 색상 옵션별 실물 비교 사진과 다이어리·노트 내지 구성 이미지
- 상세 이미지 확대 보기, 이전·다음 탐색, 레진 DIY 키트 완성 예시
- 다이어리 1권을 포함한 3배 가치 랜덤박스의 품목군·최소 수량·가격 보장 구성표
- 카테고리와 분위기를 반영해 섞이는 소형 관련 상품 추천
- 목록과 상세 이미지에 동일한 정사각형 프레임·여백 규칙 적용
- 목록·상세·장바구니·결제 전반의 가독성 중심 타이포 체계
- 데스크톱과 모바일에 맞춘 반응형 레이아웃

## 로컬 실행

```bash
node preview-server.js
```

브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다. 상품·가격·브랜드 정보는 포트폴리오용 예시이며, 결제 화면에서는 실제 승인이나 개인정보 전송이 발생하지 않습니다. 장바구니와 찜 정보는 브라우저 로컬 저장소에 보관됩니다.
